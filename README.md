# Data Analysis with Pandas & Matplotlib

Exploratory data analysis of a public dataset on fatal police shootings in the US, completed as part of a data analytics training program.

## What's inside

- Data loading and cleaning (encoding issues, dropping missing values)
- Distribution by gender
- The 7 most common weapons involved
- Age groups: under 25 vs. 25 and above
- Distribution by race, including a pie chart of ratios

## Tools

Python, pandas, Matplotlib, Jupyter Notebook

## How to run

Open the notebook in Jupyter or Google Colab and run the cells in order.
